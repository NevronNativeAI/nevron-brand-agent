A plugin for Claude Code

Nevron files, built the way the house builds them.

An advisor on any Nevron work you are already building, and six skills that produce the finished file — no InDesign, no Word, no PowerPoint.

Install — two commands

/plugin marketplace add NevronNativeAI/nevron-brand-agent
/plugin install nevron-brand

Restart Claude Code if the skills do not appear.

Update — one

/plugin update nevron-brand

For new bulk imagery, also run /plugin marketplace update nevron-brand.

Suggested companionThe codex-coworker plugin generates imagery in place — a deck hero, an offer visual — so picture work never leaves the terminal for a third-party tool. Optional; needs the Codex CLI signed in with a ChatGPT account.

01 — The agent

An advisor first, a file factory second

Most of the time you are not asking for a PDF. You are part-way through something — a web app, a landing page, a slide, a client document — and you want to know whether it is on brand. Bring the agent into that work and it reviews what you already have, in whatever you are building it in.

It knowsSo it can
The palette and its token namesTell you which blue, and what to call it in code
The type scale and the fallback chainCatch a face that is not the house face
Logo variants and clear spacePick the right lockup for the ground it sits on
The icon libraryVerify an icon exists rather than invent a name
The frame rules, guidelines 2.4Stop a frame being used as a border
Web, deck, document and print guidelinesReview against the guidelines, not against taste

It answers in your language — Slovenian if you write Slovenian — and it explains the why behind a rule rather than citing it. Where it disagrees with you, it says so and gives the reason.

What it will not do

  • Invent a brand asset. Missing icon or illustration? It says so.
  • Take assets from elsewhere on your disk. Finding a file is not permission.
  • Generate imagery unprompted — and never a real named property.
  • Round a corner. Radius 0 is a hard rule.
  • Hide a gap. What it cannot reproduce faithfully, it warns about.

02 — Skills

Six skills, six kinds of file

When you do want a finished file, these produce one. Every render below came out of the skill it sits under, built from the example that ships with it. Type the command, or just describe the thing you want.

Abstract deck

16:9 HTML + PDF

For when the point is an idea — a philosophy, a market read, the case for a partnership. Dark slides, enormous light type, one thought at a time.

/nevron-brand:presentation-abstract
  • You giveThe argument — what the room should believe by the end
  • You getA 16:9 HTML deck and a PDF, one idea per slide

Full document

A4 PDF

Reports, guides, specifications, proposals — anything that wants a cover and a contents page. The house Word template, without Word.

/nevron-brand:nevron-document
  • You giveContent as Markdown, a title, a date, a topic icon
  • You getCover, disclaimer, auto-numbered contents, body, back cover

Short document

A4 PDF

Same engine, no front matter. Letters, memos, meeting notes, checklists — content from line one.

/nevron-brand:nevron-document-nocover
  • You giveThe content, and who it is for
  • You getNumbered sections under the running header, back cover

Product datasheet

A4 PDF

Spec sheets for set-top boxes, servers and remotes. The InDesign house style, rebuilt in HTML.

/nevron-brand:datasheet
  • You giveModel, positioning line, specifications, product photography
  • You getHatched cover, dimensioned overview, ports band, spec tables

Service report

A4 PDF

What an engineer leaves behind after a site visit — a fixed skeleton, then captioned photographs.

/nevron-brand:service-report
  • You giveCustomer, property, dates, what was done, site photographs
  • You getIntroduction to signature, then the attachments page

Client offer

Web page + PDF

A priced ponudba as a page you send a hotel, with a validity countdown and the pilot timeline.

/nevron-brand:offer
  • You giveThe property, the modules, and which pricelist to use
  • You getAn upload-ready folder for clients.nevron.co, plus a PDF

03 — Workflow

Three steps, every time

  1. You describe it, Claude writes the input

    A data.json lands in a working folder. Wrong number, wrong title? Edit that file — rebuilding is instant.

  2. A plain Node script fills the house template

    Four builders serve all six skills. No dependencies, no npm install.

  3. Chrome prints it

    To PDF, and to one PNG per page with --png. The HTML stays beside the PDF, so a fix never means starting over.

Keep the .json.

Next quarter's version is a few edited values, not a new conversation.

05 — Assets

1.7 MB in the plugin, the heavy material in the clone

Claude Code caches every version of a plugin and never prunes it, so bulk imagery stays in the marketplace clone — fetched once, shared by every version.

In the pluginIn the clone
Tokens, BRAND.md, 7 logo variants, 128 icons, 19 cover frames, the skills themselves Product screenshots, illustrations, photography and the guideline PDFs

Resolved automatically. To point at a clone somewhere else:

setx NEVRON_BRAND_LIBRARY "C:\path\to\nevron-brand-agent"

06 — Troubleshooting

If something breaks

SymptomFix
Skills appear twice, bare and namespacedLeft over from the old copy-install — run the migration script below
Chrome not found. Set CHROME_PATH.Point CHROME_PATH at the binary
A build stops on a missing assetSet NEVRON_BRAND_LIBRARY
Type looks wider and looser than expectedExpected — Open Sans is standing in for Neue Haas Unica

Coming from the old hand-install

Dry run first — it lists what it would remove and touches nothing else:

powershell -ExecutionPolicy Bypass -File scripts\migrate-from-hand-install.ps1
powershell -ExecutionPolicy Bypass -File scripts\migrate-from-hand-install.ps1 -Apply

Brand items only

The nevron.co website skills (nevron-copy, nevron-post, nevron-publish, nevron-seo) and the nevron-site agent are never touched.
